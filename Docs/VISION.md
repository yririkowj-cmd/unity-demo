# 游戏愿景文档（VISION）

> 本文档是"三层文档体系"的第一层：**只增不删**。
> 想到什么就往里加，不整理、不排序、不判断优先级——它是"脑子的备份"。
> 当前 MVP 要做什么，看 `MVP-CHECKLIST.md`；分期兑现计划看第 10 节。

**一句话定调：**

> 一个以"私人军火库"为锚点的低压力武器/角色游乐场——
> 单人上手即爽，好友同屏切磋，社区工坊续命。

不是竞技，不是刷刷刷，是把"我想爽、想秀、想看、想和朋友一起瞎玩"做成主玩法本身。

## 0. 定位与差异化

| 维度 | Garry's Mod | 瓦洛兰特 | 鸣潮 | 本作 |
|---|---|---|---|---|
| 入口体验 | 空地图 + 工具枪，懵圈 | 匹配对局 | 登录做任务 | 私人军火库，落地即可玩 |
| 核心爽点 | 物理恶搞、建载具 | 竞技对抗 | 抽卡养成 | 武器手感、近战动作、皮肤反馈、角色观赏 |
| 学习成本 | 高（工具枪/焊接/Lua） | 中 | 中 | 拿起就能打，零教学 |
| 社交形态 | 公开服 + 陌生人 | 匹配 + 陌生人 + 输赢压力 | 单人为主 | 好友私房 + 展示切磋 + 无输赢 |
| 创作生态 | 全靠工坊撑着 | 无 | 无 | 本体先扎实，mod 是扩展不是必需 |
| 辨识度 | 没有固定样貌 | 强 | 强 | **军火库空间 = 品牌锚点** |

Gmod 胜在"无限"，败在"没形状"。本作要做的是**有形状的沙盒**。

## 1. 核心体验

玩家想要的三层，从下往上：

1. **感官满足**：枪械手感、近战挥砍、角色模型、皮肤反馈——"爽"的来源
2. **拥有感**：皮肤收藏、角色收集、审美认同——"这是我的" 
3. **自由支配权**：不被规则逼着走、想玩什么玩什么、想看什么看什么

现有多数游戏的问题：**把好东西锁在了不好玩的规则后面**——
瓦洛兰特的好皮肤锁在竞技里（受挫），鸣潮的好角色锁在长草期后（无事可做），ARPG 的好动作锁在刷刷刷里（疲劳）。

本作做的事：**把这些元素从规则里解放出来。**

核心循环：

```
打开游戏 → 进入私人军火库 → 拿起一把枪 → 打靶 → 手感反馈拉满
   → 换皮肤整套感官变化 → 朋友进来一起打靶/比连招/逛探索地图
   → 找到新武器回军火库展示 → 循环
```

关键词：**武器手感 × 角色展示 × 无压力社交 × 玩家创作**

## 2. 三层产品架构

### 2.1 锚点层：私人军火库 + 展示厅（永远在线）

不管装多少 mod，这里永远在，是游戏的"脸"。

```
┌─────────────────────────────────────────────────┐
│                 入口门（推开进入）                │
│                                                 │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌─────────────┐   │
│  │武器墙│ │近战  │ │角色  │ │ 射击通道     │   │
│  │左墙  │ │展柜  │ │展示台│ │（靶子/木桩） │   │
│  │步枪  │ │刀    │ │角色A │ │ 🎯 🎯 🎯    │   │
│  │手枪  │ │剑    │ │角色B │ │ 可调距离     │   │
│  │霰弹  │ │斧    │ │角色C │ │             │   │
│  └──────┘ └──────┘ └──────┘ └─────────────┘   │
│                                                 │
│  ┌─────────────────────────────────────────┐   │
│  │ 沙发区 / 好友互动角   │ 出口门→探索地图  │   │
│  │（拍照/表情/观战）     │（传送/步行）     │   │
│  └─────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

交互细节（决定"手感"）：

- **拿枪**：悬停微微浮起/发光 → 点击拿起 → 第一人称手持，能看到枪身细节 → 滚轮切换检视模式
- **试手感**：门口就有靶子，拿起来直接打；音效在房间里回荡；切枪动画流畅到愿意反复切
- **换皮肤**：实时生效，声音/特效/粒子全变
- **角色**：呼吸待机动画、可旋转、可放大看细节、可换装、可摆 pose、可拍照
- **好友**：站旁边一起打靶比分数、互相展示皮肤、坐沙发

### 2.2 玩法层：本体自带"零压力爽感"（不依赖 mod）

- 打靶模式：静态/移动/计时/连击评分，无敌人反杀
- 近战试炼：挥砍轨迹、弹反、处决动画，打分不算输赢
- 合作 PvE 波次（可选）：AI 靶子/假人，难度滑块自选
- 好友切磋场：不是死斗，是"连招表演赛"——系统判华丽度/命中率/创意，不弹 VICTORY/DEFEAT
- 皮肤试衣间：枪皮、刀光、击杀特效、音效包实时切换

**本体内容公式：武器手感 × 角色展示 × 低强度靶场 × 好友同屏 = 前期不空心**

### 2.3 创作层：三级台阶（别一上来逼人写代码）

| 档位 | 面向 | 能做什么 | 工具 |
|---|---|---|---|
| 第一档 · 轻量工坊 | 所有人 | 订阅武器皮肤、刀光特效、角色外观、靶场地图；拖拽式挑战编辑器 | 订阅 + 可视化 |
| 第二档 · Maker DLC | 愿意深玩的 | 可视化拼武器（枪管+握把+后坐力曲线+特效）、角色部件混搭、动作替换、简单逻辑节点 | 官方可视化编辑器 |
| 第三档 · 硬核 Mod | 程序/技术美术 | 新武器类型、新敌人 AI、新探索区域、新剧情、新规则 | Lua/C# API + 资源热重载 |

**关键原则：不装任何 mod，本体也完整；装了 mod 是锦上添花。**

## 3. 无压力社交：做成系统，不是口号

| 压力源 | 解法 |
|---|---|
| 输赢压力 | 取消段位/积分，只用"表现分/回放/截图" |
| 陌生人压力 | 默认私房邀请制；公开大厅可进但无匹配强制 |
| 强度焦虑 | 所有 PvE 难度可调，AI 不会越打越变态 |
| 嘲讽环境 | 屏蔽文字，只留表情/掌声/慢动作重播点赞 |
| 长草期 | 角色不绑剧情，展示厅天天能看；新内容靠工坊续命 |

好友一起玩的真实场景：

> A 拿新刀在木桩连招，B 绕后观战按"帅"打分；
> 然后俩人进射击场比"盲狙移动靶"，输了换个音乐再来；
> 最后回大厅，切角色换衣服，截张双人海报。

## 4. 内容供给：角色/剧情怎么不"塑料"

个人团队做不出鸣潮级剧情和角色量产，解法：

- **角色不靠剧情撑，靠"展示价值"撑**：人设卡 = 风格标签（冷艳/机械感/和风/废土），待机动作、衣料物理、语音碎片就够了
- **官方只做"标杆角色"**：前期 4–6 个高精度角色，证明质感上限
- **产能交给工坊**：开放角色模板 + 骨骼规范，同人作者出皮肤/动作/新脸
- **剧情退化成"氛围碎片"**：军火库日志、武器铭文、角色语音彩蛋，不强制看

角色是**可收藏可把玩的手办**，不是叙事载体。

## 5. 探索地图：不是开放世界，是"世界观游乐场"

军火库是家，探索地图是后院/世界。**探索是你想去，不是你必须去。**

| 传统开放世界 | 本作探索地图 |
|---|---|
| 跑图做任务拿奖励 | 逛世界观场景拿收藏品 |
| 强制推进剧情 | 碎片化叙事，看多少随你 |
| 地图越大越跑越累 | 区域紧凑，每个点都有明确收获 |
| 解锁后还要回来做任务 | 解锁完直接回军火库展示 |

### 5.1 区域 → 内容对应

| 区域 | 风格 | 解锁内容 |
|---|---|---|
| **废弃训练场**（初始） | 废土/军用遗迹 | 基础枪械、粗糙近战、涂装 |
| 废弃工厂 | 工业风 | 工业枪械、废土改装 |
| 沙漠试验场 | 军用科技 | 军用级武器、战术皮肤、瞄准镜特效 |
| 地下黑市 | 霓虹/赛博 | 花哨皮肤、霓虹刀光、夸张击杀特效 |
| 遗迹/神庙 | 古代神秘 | 能量武器、角色碎片（古代战士/祭司） |
| 雪原哨站 | 极地 | 极地涂装、消音器系列、冷色调皮肤 |

每个区域 = 几个精心设计的房间，每个房间藏 1–3 件可解锁物品。

### 5.2 探索玩法：寻宝 + 轻互动（不是打副本）

- 观察环境，找隐藏武器箱/角色碎片
- 简单解密：按开关、找钥匙、走对顺序
- 极低压力敌人——不是来杀你的，是来"被你测试新武器"的
- 找到的东西直接进军火库，回来就能用

**解密原则**：不卡进度（只锁隐藏/稀有物品）、类型简单多样、可跳过、支持双人协作。

### 5.3 剧情/世界观：碎片化 + 环境叙事

- 武器铭文：一句话、一个编号、一个名字
- 环境细节：工厂海报、黑市交易记录、雪原日志
- 角色语音碎片：解锁后在军火库偶尔自言自语
- 收集品日志：集齐一个系列解锁一段"档案"

世界观不需要完整故事线，只需要给武器和角色一个**来历感**。

### 5.4 军火库作为"家"的强化

- 拿到沙漠系列 → 军火库一角多一个沙色陈列柜
- 解锁角色 → 她会偶尔在大厅走动/待机
- 探索进度推进 → 军火库本身扩建（新墙面/展台/灯光）
- 收集度达标 → 解锁"客厅模式"：沙发、电视、音乐播放器

### 5.5 军火库自由设计的三个层级

1. **布局自由**（所有人）：墙面挂什么、展柜放哪、角色站哪——拖拽摆放；预设几套模板
2. **装饰自由**（进阶）：地板/墙壁/灯光/背景音乐；纪念品摆件；自定义照片框
3. **功能扩展**（mod/DLC）：加新房间（车库/室外训练场）、新展示台（全息投影）、新互动家具

约束：不管怎么摆，核心元素（武器墙、角色台、好友区）始终在，**品牌感不能丢**。

### 5.6 载具（远期）

| 类型 | 作用 | 复杂度 |
|---|---|---|
| 越野车/摩托 | 快速穿越 | 中 |
| 滑翔翼/喷气背包 | 到达隐藏点位 | 低 |
| 坦克/武装载具 | 探索时开炮 | 高 |
| 装饰性载具 | 军火库里摆着看 | 极低 |

MVP 只考虑摩托/越野车，且**手感要跟武器一样爽**（引擎声、震动、漂移粒子）。

### 5.7 在线大厅（远期，但方向已定）

一个公共空间，陌生人偶遇但无压力：

- 来去自由，不说话也行；只有功能的是商店，有探索价值的是大厅
- 隐藏纪念品 + 老玩家给新人引路 = 无压力的善意社交
- 表情/手势系统，不强制语音
- 参考：动森机场 + 命运2 社交区 + 军火库的公共版
- 限流/分频道，避免拥挤

## 6. 武器与手感（第一公民）

- 每把武器不只是数值不同，是**手感完全不同**：后坐力模式、切枪动画、开火音效、弹道视觉、击杀反馈
- 皮肤不只是贴图，是**改变整套感官**：换一把刀，挥砍轨迹、音效、粒子全变
- 玩家可混搭：枪械主体 + 任意皮肤 + 任意击杀特效 + 任意音效包
- 近战：挥砍弧线、命中停顿、弹反、处决、连招
- 靶场要"高度自由"：靶子类型/距离/速度/血量、环境（室内外/雨天/夜晚）、穿甲跳弹可视化、回放、自定义挑战分享码、好友排行榜、武器并排对比

## 7. Mod 能力分级（首发开放到第三级）

| 级别 | 能做什么 | 需要代码 | 工具 |
|---|---|---|---|
| 一级 · 内容替换 | 换皮肤/贴图/音效/特效/模型 | 否 | 文件替换 + 配置 |
| 二级 · 工坊创作 | 新皮肤、新角色外观、新靶场地图、新解密关卡 | 否 | 可视化编辑器 |
| 三级 · 逻辑扩展 | 新武器类型、新 AI 行为、新区域、新剧情、新规则 | 是（Lua/节点） | 官方脚本 API |
| 四级 · 底层扩展 | 新物理/渲染/网络模式、改核心循环 | 是 + 可能需源码 | SDK |

首发开放到三级；不改引擎底层。

脚本 API 示例（给 mod 作者）：

```lua
Weapon:new{
  name = "冰霜步枪",
  damage = 45,
  fire_rate = 0.12,
  recoil_pattern = {x = 0.3, y = 0.8},
  on_hit = function(target)
    target:apply_status("frost", 3)
    spawn_particle("frost_explosion", target.pos)
  end,
}
```

## 8. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 引擎 | Unity 6 + URP | 迭代快、C# 好调手感、资产商店省时间、Mod 生态资料最多 |
| 语言 | C# | 好找人、好维护 |
| 网络 | 本地分屏 → LAN → Steamworks | MVP 不碰服务器 |
| 动画 | Unity Animator + 现成动画包 | 不自己 K 帧 |
| Mod 预留 | Addressables + Lua（MoonSharp） | 现在不做，接口留对 |

**架构分层：**

```
Gameplay Layer（玩法）
 ├── WeaponSystem（武器数据 + 手感 + 后坐力 + 特效）
 ├── MeleeSystem（近战弧线 + 命中检测 + 反馈）
 ├── TargetSystem（靶子类型 + 计分 + 反应）
 ├── SkinSystem（皮肤挂载 + 视觉/音效替换）
 └── InteractionSystem（拾取/检视/摆放）

Space Layer（空间）
 ├── ArmorySpace（军火库房间 + 布局逻辑）
 ├── ShootingRange（靶场参数 + 模式）
 └── ExplorationSpace（探索区域 + 收集点）

Social Layer（社交）
 ├── LocalMultiplayer（分屏/输入分离）
 └── FriendSpace（串门/展示/观战）

Mod Layer（预留）
 ├── ContentLoader（Addressables 热加载）
 └── ScriptAPI（Lua 沙箱，后期开放）
```

## 11. 零散想法（随时追加）

- 大厅里的"陌生人带新人找隐藏纪念品"——无压力社交的关键设计
- 角色获取不是抽卡，是"你在探索中找到她"——比抽卡有仪式感
- 敌对 NPC = 人形靶，难度可调，可开"和平模式"只当氛围
- 探索进度可以改变军火库的样貌（扩建/新灯光）
- 武器变体撑内容量：同一把枪 5 种皮肤 = 5 种感官体验
- 探索地图做"小但密"，不做"大但空"
