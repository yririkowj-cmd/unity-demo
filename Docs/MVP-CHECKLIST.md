# MVP 检查清单（10 周，每周打勾）

> 三层文档体系的第二层：**只写"现在就做"的事**。
> 愿景看 `VISION.md`，分期计划看 `VISION.md` 第 10 节。
>
> 用法：打印出来贴墙上，每周日花 30 分钟对着勾。勾不上就砍功能，别硬扛。

**MVP 目标：验证"手感 + 锚点 + 社交"三件事，不是做一个完整的游戏。**

## 第 1–2 周：军火库 + 第一把枪

- [x] 房间里能走路（CharacterController 跑通）
- [x] 军火库白盒：墙面、展台、门口靶位、出口门
- [ ] 墙上有一把枪，能拿起来（走近 → 提示 → E 拿起）
- [ ] 拿起枪有重量感/手感反馈（鼠标/手柄震动）
- [ ] 门口有靶子，能开火打中
- [ ] 开火有音效 + 视觉反馈（枪口焰/弹孔/命中粒子）
- [ ] 击中靶子有计分/反馈
- [ ] 能放下枪、再拿起
- [ ] 找至少 3 个人试玩，问"想不想多开两发"

⚠️ 这周不碰：探索地图、角色、皮肤、Mod、UI 美化

---

## 第 3–4 周：武器手感打磨 + 扩充

- [ ] 第二把枪（手感明显不同：射速/后坐力/音效）
- [ ] 第三把枪
- [ ] 近战武器（刀）：挥砍弧线 + 命中反馈 + 切刀动画
- [ ] 每种枪的后坐力曲线单独可调
- [ ] 开火间隔/换弹时间/弹道散布有区分
- [ ] 连续调手感，直到朋友说"这把枪手感不一样，挺爽"
- [ ] 靶子类型：静态/移动/木桩（至少 3 种）
- [ ] 移动靶有规律路径，能打中

⚠️ 这周不碰：网络、社交、剧情、解密

---

## 第 5–6 周：皮肤挂载 + 角色展示

- [ ] 每把枪至少 2 套皮肤（换贴图/颜色/质感）
- [ ] 换皮肤时音效也变
- [ ] 换皮肤时粒子/枪口焰也变
- [ ] 换皮肤实时生效（不用退出重进）
- [ ] 角色展示台：1 个角色，待机动画（呼吸/微动）
- [ ] 能旋转角色 360°
- [ ] 能放大看细节（镜头推进）
- [ ] 能切换 1–2 套服装
- [ ] 能拍照（隐藏 UI 截图）

⚠️ 这周不碰：工坊开放、Mod 工具、在线功能

---

## 第 7–8 周：本地双人 + 探索区域

- [ ] 本地分屏（两个手柄/键鼠各控一个角色）
- [ ] 两人同时拿武器、同时开火，互不干扰
- [ ] 两人同时打同一组靶子，有分数对比
- [ ] 好友可以"串门"（第二个玩家进入同一军火库）
- [ ] 军火库后门出口 → 加载一个小探索区域
- [ ] 探索区域：3–5 个收集点
- [ ] 至少一个收集点是隐藏的（不在主路上）
- [ ] 找到的东西回到军火库后，有明确变化（墙上多一把枪/台子多一个角色）
- [ ] 解密极简（不超过 1 个简单交互）
- [ ] 探索区域没有敌人，或敌人只是站着的靶子

⚠️ 这周不碰：在线大厅、载具、阵营系统

---

## 第 9–10 周：整合 + 打磨 + 测试

- [ ] 所有功能串起来能完整跑一遍（进游戏→拿枪→打靶→换皮肤→看角色→探索→回来）
- [ ] 没有崩溃/卡死/穿墙等硬伤
- [ ] 手感再调一轮（后坐力/命中停顿/切枪节奏）
- [ ] 录制一段 30 秒实机视频
- [ ] 找 10 个人试玩（朋友/同学/开发者社区）
- [ ] 收集反馈，只记一个问题："你还想再玩一次吗？"
- [ ] 根据反馈修最影响手感的 3 个问题
- [ ] 截图/录屏，存档作为"MVP 完成"的里程碑

## 全程红线（任何时候都不碰）

- [ ] ❌ 不碰在线匹配/排位/服务器逻辑
- [ ] ❌ 不碰剧情对话系统
- [ ] ❌ 不碰敌人 AI / 战斗系统
- [ ] ❌ 不碰载具/驾驶
- [ ] ❌ 不碰创意工坊/Mod 工具开放
- [ ] ❌ 不碰移动端/主机适配
- [ ] ❌ 不碰账号/云存档
- [ ] ❌ 不碰美术精修（白盒能跑就行）
- [ ] ❌ 不碰第二张探索地图（第一张还没验证）

> 注：红线里的"不碰敌人 AI"意味着——此前讨论的"阵营/Team 模型"和"第四步敌人系统"都**推迟到 MVP 之后**。
> 战斗系统只需要够验证武器伤害与靶子反馈即可。

## 每周必做（写在日历上）

- [ ] 周日花 30 分钟回看本周进度，勾清单
- [ ] 如果这周没勾上任何一项 → 下周砍掉一个功能，别硬扛
- [ ] 如果连续两周没进展 → 停下来玩别的游戏找灵感，别耗着
- [ ] 有任何新想法 → 写进 `VISION.md`，这周不做
- [ ] 每周至少找一个人看你的进度（截图/录屏/现场试玩）

## 要避开的 7 个早期风险

| # | 风险 | 防法 |
|---|---|---|
| 1 | **手感翻车**（最致命） | MVP 前 4 周只做一把枪一个靶子；手感是唯一 KPI |
| 2 | **范围膨胀**（最容易发生） | 只做本清单里的，其他全写进 `VISION.md` 归档 |
| 3 | **内容空心**（单人团队最大坑） | 早期开放工坊；武器靠变体撑量；探索"小但密" |
| 4 | **一个人扛所有角色** | 能买资产就买；每周只推进一件；找个互补的人 |
| 5 | **没人玩/没人理解** | 开发过程本身当内容；早期找 10–20 个测试者 |
| 6 | **技术债/架构返工** | `WeaponData` SO、Addressables 预留、Lua 接口预留 |
| 7 | **热情耗尽**（最隐蔽） | 设可见里程碑；累了去玩别的找灵感；找人聊 |
